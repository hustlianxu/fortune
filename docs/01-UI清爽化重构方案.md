# UI 清爽化重构方案（v0.2.0）

> 对应需求目标 #1「界面清爽」与 #2「代码优化」。本方案解决 `00-需求分析与设计原则.md` 诊断出的 6 类根因。

## 一、主题变量收敛（theme.wxss）

### 1.1 新增语义变量

在原有变量基础上，补齐缺失的语义 token，让页面 wxss 不再硬编码：

```css
page {
  /* —— 主色：由"科技紫"调淡为更稳重的"靛蓝"，降低视觉刺激 —— */
  --primary-color: #4a6cf7;     /* 原 #6c63ff 偏艳，调为偏蓝的靛 */
  --primary-soft: #eef2ff;      /* 主色 8% 背景填充，用于 tag/选中态 */
  --primary-color-rgb: 74,108,247;

  /* —— 交易语义色（独立于涨跌色）—— */
  --txn-buy: #4a6cf7;           /* 买入：主色蓝 */
  --txn-sell: #f5a623;          /* 卖出：琥珀橙 */
  --txn-transfer: #8e8e93;      /* 转账：中性灰 */
  --txn-income: #34c759;        /* 分红/利息：清新绿（非涨跌绿） */

  /* —— 卡片规范统一 —— */
  --radius-card: 20rpx;
  --radius-sm: 12rpx;
  --shadow-card: 0 2rpx 12rpx rgba(0,0,0,0.04);

  /* —— 间距规范（4 的倍数栅格）—— */
  --space-xs: 8rpx;
  --space-sm: 16rpx;
  --space-md: 24rpx;
  --space-lg: 32rpx;
}
```

### 1.2 删除/替换的"花哨"用法

| 旧用法 | 新做法 |
|--------|--------|
| AI 入口 `linear-gradient(#667eea→#764ba2)` | 删除渐变，改为白卡 + 主色文字 + 右箭头 |
| dashboard 头部紫渐变 | 保留为**唯一**渐变，但色值统一到 `--primary-color` 系 |
| 各页面硬编码 `#6c63ff` | 全部替换为 `var(--primary-color)` |
| 各页面硬编码 `#8e8e93` | 替换为 `var(--text-tertiary)` |
| 各页面硬编码 `#f0f0f0` | 替换为 `var(--border-color)` |
| tag 五种饱和色块 | 改为 `--primary-soft` 浅底 + 深字，仅用主色一种 |

## 二、页面级改造清单

### 2.1 Dashboard（首页）
- **保留**：总资产 Hero 卡（唯一渐变焦点）。
- **改造**：
  - AI 入口卡去渐变、去大 emoji，改为单行列表项样式（图标小号 + 文字 + 箭头）。
  - "快捷操作"区合并 AI/导入/流水入口为统一的「更多功能」列表，行高一致。
  - 饼图图例去除彩色 dot 的描边，颜色饱和度统一降低。
- **效果**：首屏从 4 种色块（紫渐变+紫渐变+蓝+橙）降到 2 种（Hero 紫 + 涨跌红绿）。

### 2.2 Holdings（持仓列表）
- 账户分组标题去 emoji，改为纯文字 + 右侧合计。
- 持仓项的 tag 由实色块改为浅底深字（`--primary-soft`）。
- 盈亏数字保留红绿，但移除多余的背景药丸。

### 2.3 Transactions（交易流水）
- **核心修复**：交易类型徽章不再复用涨跌色。
  - 买入 → `--txn-buy`（蓝）
  - 卖出 → `--txn-sell`（橙）
  - 转账 → `--txn-transfer`（灰）
  - 分红/利息 → `--txn-income`（清新绿）
- 徽章由"满色块"改为"浅底 + 左侧 4rpx 色条"，进一步降噪。
- 汇总卡去掉双行背景区分，改为细分隔线。

### 2.4 Holding Detail（持仓详情）
- 顶部盈亏区简化：只保留「当前市值 / 持仓盈亏 / 持仓占比」三栏。
- 去除装饰性渐变边框。

### 2.5 Account Detail（账户详情）
- 账户头部卡去渐变，改为白卡 + 大字号余额。
- 持仓子表与 holdings 页样式对齐，复用同一套 class。

## 三、实施约束

1. **禁止**在页面 wxss 出现新的 `#xxxxxx`，必须用变量。审计命令：
   ```bash
   grep -rn '#[0-9a-fA-F]\{6\}' miniprogram/pages --include='*.wxss'
   ```
   重构后该命令除 rgba 外应零命中。
2. 圆角统一用 `--radius-card` / `--radius-sm`，不得直接写数值。
3. 阴影统一用 `--shadow-card`。

## 四、验收标准

- [ ] 首屏（dashboard）色块种类 ≤ 2（Hero 渐变 + 涨跌色）
- [ ] `grep` 硬编码颜色在 pages/ 下零命中（rgba 除外）
- [ ] 交易徽章颜色与涨跌色不再共用 token
- [ ] 所有页面圆角/阴影值统一来自变量
